PROJECT_NAME: ClimateDataVisualizer

## ClimateDataVisualizer

### Description
ClimateDataVisualizer is a web application built to democratize access to climate data and provide visual insights into climate patterns and trends. Given the news of potential dismantling of a major climate research institution, this project aims to empower individuals with the tools to explore and understand climate data independently. By using this app, users can upload datasets, visualize them through interactive charts and maps, and gain a deeper understanding of climate issues without relying on specific institutions.

### Features
- **Data Upload**: Users can upload their own climate datasets in CSV format.
- **Interactive Visualizations**: Provides line charts, bar graphs, and geographical heatmaps to analyze data.
- **User-friendly Interface**: Easy-to-use interface designed for non-experts in data visualization.
- **Responsive Design**: Works well on both desktop and mobile devices.

### Technologies Used
- **Frontend**: HTML, CSS, JavaScript, React.js
- **Backend**: Node.js, Express
- **Data Visualization Libraries**: D3.js, Leaflet.js
- **APIs**: Various open-source climate data APIs

### Installation
To run ClimateDataVisualizer locally, follow these steps:

1. **Clone the Repository**:
   bash
   git clone https://github.com/yourusername/ClimateDataVisualizer.git
   cd ClimateDataVisualizer
   

2. **Install Dependencies**:
   - For frontend (inside `client` directory):
     bash
     npm install
     
   - For backend (inside `server` directory):
     bash
     npm install
     

3. **Run the Application**:
   - Start the frontend:
     bash
     cd client
     npm start
     
   - Start the backend:
     bash
     cd server
     node server.js
     

### Usage
1. **Upload Data**: Navigate to the "Upload" section of the web app. Choose a CSV file containing climate data and upload it.
2. **Visualize Data**: Once the data is uploaded, you can use the various visualization tools provided to create line charts, bar graphs, and heatmaps.
3. **Explore Trends**: Use the interactive features of the charts and maps to explore different climate trends and patterns in your dataset.
